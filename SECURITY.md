# Segurança

Este projeto é um site estático em HTML, CSS e JavaScript. Não possui backend, formulários de coleta ou funcionalidades de armazenamento de dados pessoais no site. O provedor de hospedagem pode registrar dados técnicos de acesso, conforme sua própria política de privacidade.

Se encontrar uma vulnerabilidade, entre em contato com o mantenedor por um canal privado já conhecido e inclua passos para reproduzir o problema, sem compartilhar credenciais ou dados de terceiros. Não publique detalhes sensíveis em uma issue pública.

O canal privado de reporte no GitHub ainda precisa ser ativado pelo mantenedor. Até lá, não há um endereço específico de segurança configurado neste repositório.
