# You Living in UK

Primeira versão da página de apresentação, em HTML, CSS e JavaScript estáticos.

## Prévia local

```sh
python3 -m http.server 8000
```

Acesse http://localhost:8000. As fotografias foram fornecidas pelo proprietário do projeto.

## Publicação

A configuração no PythonAnywhere depende da conta e do domínio disponível. Antes de publicar, definir canal de contato, validar os detalhes comerciais e conferir a configuração da aplicação existente. A demonstração das telas de celular é ilustrativa e não representa uma área de aluno funcional.
